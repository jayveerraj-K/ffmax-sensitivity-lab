# FFMAX Sensitivity Lab

A polished, mobile-first browser interface for building, tuning, and saving Free Fire MAX sensitivity starting points.

### Features
- Profile generator based on screen size, DPI, play style, and focus
- Interactive sensitivity controls
- Local preset storage
- Copy-to-clipboard profile export
- Responsive gaming-style interface
- No dependencies or backend

Open `index.html` in a browser to run it.

This project is a calibration/practice utility. It does not modify the game, automate aiming, bypass anti-cheat systems, or interact with game files.
